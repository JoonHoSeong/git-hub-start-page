# Chrome 웹 스토어 등록 설명문 (초안)

## 짧은 설명 (Short description, 최대 132자)

내가 정한 키워드(LLM, MCP 등)로 GitHub 트렌딩 저장소를 모아보는 새 탭. 실시간 급상승 순위와 번역까지.

## 긴 설명 (Detailed description)

GitHub Topic Radar는 매일 GitHub 트렌딩 페이지를 뒤지는 대신, **내가 관심 있는 주제만 골라서** 떠오르는 오픈소스 저장소를 한눈에 보여주는 확장 프로그램입니다.

**주요 기능**

📡 **주제별 큐레이션**
LLM, MCP, Skills 같은 기본 주제부터 Frontend, Backend, DevOps, Security까지 다양한 프리셋을 제공하며, 원하는 키워드로 나만의 주제도 자유롭게 추가할 수 있습니다. 필요한 주제만 켜고 순서도 원하는 대로 정렬하세요.

📈 **진짜 트렌드, 진짜 급상승**
GitHub API는 "최근 얼마나 별을 받았는지"를 알려주지 않습니다. 그래서 자체 서버가 매시간 공개 데이터를 수집해 실제 별표 증가량(모멘텀)을 계산합니다. 트렌드순 / 급상승순 / 스타순 / 포크순 / 최신순 등 원하는 기준으로 정렬하세요.

🔖 **로컬 북마크**
GitHub 스타와는 별개로, 브라우저에만 저장되는 나만의 북마크로 관심 저장소를 따로 관리할 수 있습니다.

🌐 **온디바이스 번역**
Chrome 내장 AI(Gemini Nano)를 이용해 저장소 설명을 17개 언어로 번역합니다. 외부 서버로 데이터를 보내지 않고 브라우저 안에서 즉시 처리됩니다.

✨ **정확도 검증 & 요약**
Chrome 내장 AI가 검색 결과의 주제 관련성을 다시 확인하고, 짧은 요약도 함께 보여줍니다.

🌓 **다크/라이트 글래스모피즘 UI**
눈에 편안한 다크 모드와 라이트 모드를 지원하며, 새 탭을 열 때마다 반가운 화면을 마주하게 됩니다.

🆕 **신규 감지 & 검색**
지난 방문 이후 새로 나타난 저장소는 NEW 배지로 표시되고, 결과 안에서 바로 검색도 가능합니다.

**설치 후 사용법**

툴바 아이콘을 클릭하면 전체 화면으로 GitHub Topic Radar가 열립니다. 원하는 주제 탭을 고르고, 필요하면 GitHub 계정으로 로그인해 API 제한을 늘리세요(선택 사항).

**개인정보**

수집하는 개인정보가 없습니다. 모든 설정과 북마크는 브라우저에만 저장되며, 트렌드 계산에 쓰이는 데이터는 GitHub에 공개된 저장소 통계입니다. 자세한 내용은 개인정보처리방침을 참고하세요.
